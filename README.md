# PCartLoader

This is a simple python Qt app for Linux built on PySide6 and watches for newly connected devices. If a `cartridge.ini` file is found, PCartLoader launches the application targeted by the config file.

When launched, the application immediately minimizes to the system tray. Right click to access the settings, config file editor, list of attached cartridges, and toggle cartridge autorunning. In the settings menu, you can specificy what local applications to use with various cartridge target types.

**Note: It is neccessary to turn on automatic device mounting in your operating system's settings.**

## Compatibility

PCartLoader currently supports Windows 10&11 and Linux distributions with Wayland desktop environments that support Qt.

## Install

### Linux

PCartLoader is distributed as an AppImage built using [pyproject-appimage](https://pypi.org/project/pyproject-appimage/). Simply download the latest version from the [Releases](https://github.com/carlgoshert/PCartLoader/releases) page, or build from source using:
```
curl -L -o pcartloader.zip https://github.com/carlgoshert/PCartLoader/archive/refs/heads/main.zip
unzip pcartloader.zip
cd PCartLoader-main
python build-linux.py
```
I recommend using [Gear Lever](https://flathub.org/en/apps/it.mijorus.gearlever) to install and manage the AppImage file. Gear Lever and other AppImage updaters will be able to download and install updated versions as they are released.

### Windows

An executable installer for Windows is made available in each [Release](https://github.com/carlgoshert/PCartLoader/releases). The installer is generated by InstallForge. You can compile an executable from source with the following (and generate your own installer if desired, although not required):

```
curl -L -o pcartloader.zip https://github.com/carlgoshert/PCartLoader/archive/refs/heads/main.zip
Expand-Archive -PATH pcartloader.zip
cd PCartLoader-main
python build-windows.py
```


## Usage

First, enable automounting for removable media in your computer's settings ("Device Auto-Mount" on KDE Plasma)

Next simply launch PCartLoader.AppImage and allow it to run in the background. Plug a [PCart Reader](https://github.com/carlgoshert/PC_Cartridge_System) into your computer and slot in a cartridge. Alternatively, any removeable USB media can be used, such as flash drives or SD card readers. Once the media is recognized by your computer, PCartLoader will automatically launch the program designated by your `cartridge.ini` file.

For more information on configuration and usage, [see the wiki](https://github.com/carlgoshert/PCartLoader/wiki/Home).
